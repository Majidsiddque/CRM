## 🚀 Run it in 5 seconds

1. Keep `index.html` on your computer
2. Double-click it
3. Done. It opens in Chrome.

## ✨ What you get

| | Section | What you can do |
|---|---|---|
| 🏠 | **Home** | See the latest admissions, jump to any section |
| 📊 | **Dashboard** | Totals, fees, monthly admissions chart, status donut |
| 👩‍🎓 | **Students** | Search, filter, sort, add and delete students |
| 📚 | **Courses** | Browse course cards with fee and seats filled |
| 📨 | **Enquiries** | Add enquiries from a course card and move them from New to Admitted |

## 🧭 Move around

⬅️ ➡️ keyboard arrows &nbsp;•&nbsp; `/` search students &nbsp;•&nbsp; ◐ dark or light &nbsp;•&nbsp; 🖱️ top tabs &nbsp;•&nbsp; 🔘 bottom arrows &nbsp;•&nbsp; 📱 swipe

## 📖 How to use each part

<details>
<summary><b>👩‍🎓 Students</b></summary>

- **Search** by name, city or course
- **Filter** by Active, Pending or Inactive
- **Sort** by clicking a column heading
- **Add** with **+ Add student**, then **Save student**
- **Delete** with the Delete button on the row
</details>

<details>
<summary><b>📊 Dashboard</b></summary>

Numbers and charts update by themselves when you add or delete a student.
</details>

<details>
<summary><b>📨 Enquiries</b></summary>

When you talk to someone, press **Move to Counselling done**. When they join, press **Move to Admitted**.
</details>

<details>
<summary><b>🎨 Change colours and text</b></summary>

Everything is in `index.html`:

- Colours: values under `:root{...}`
- Name: search for `Institute CRM`
- Courses and enquiries: the `courses` and `enq` lists in the script
</details>

## ⚠️ Good to know

Data is saved in your browser (localStorage), so it stays after refresh on the same computer. There is no login or server yet.
