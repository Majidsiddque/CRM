🔐 Security Implementation Details

Database Schema

Tables with RLS: institutes, people, students, courses, enquiries, payments, webhook_events

Policy Name: inst_isolation - Enforces WHERE institute_id = current_setting('app.institute_id')::uuid

Database User: app_user (non-superuser, cannot bypass RLS)

Automated Test Suite

Total Tests: 127 (20 application + 88 isolation + 19 CRM API)

Coverage: Plain queries, joins, subqueries, CTEs, unions, cross joins, insert-select, missing/wrong IDs

CI/CD: All tests run on every commit via GitHub Actions

Razorpay Integration

Features: Test payment links, webhook signature verification (HMAC-SHA256), idempotent payment recording

Security: Duplicate webhook detection, event-level deduplication, institute validation

Cloud Deployment

Infrastructure: AWS ECS (Fargate), RDS (PostgreSQL), ALB, ECR

IaC: Terraform (staging environment configured)

Monitoring: Health checks, budget alerts configured
